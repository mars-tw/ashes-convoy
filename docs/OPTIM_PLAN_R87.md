## 八大面向

1. 美術：做 UI 間距、文字層次與狀態色；沿用已授權素材，不新增角色／地圖原畫。
2. 按鈕：做拇指區、64px 甩尾、至少 44px 其他控制，直橫與矮桌機可達性。
3. 選單：做可關閉的路線圖、暫停與返回；保留基地既有導覽。
4. 人物：本輪不改造型，避免破壞已存在辨識度與動畫契約。
5. 地圖模型：做三條路的可玩任務、伏擊／補給接線；沿用環境素材，不以方塊冒充新地圖。
6. 技能：做甩尾操作、冷卻與觸控取消、補給搭配收益。
7. 角色樣子：不新增或替換角色，不宣稱重新通過三視圖／明度美術驗收。
8. 動作流暢：保留 walk／attack／hurt／death 真幀及命中時序；新伏擊使用既有敵人動畫，不增加單圖晃動。
